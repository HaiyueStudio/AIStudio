# 交互探索、正式回归与证据读取恢复

日期：2026-11-22。保持当前里程碑状态。

桌球工程在错误屏幕坐标上声明了击球断言。之后修正坐标的探测虽然通过，旧断言仍被永久冻结；成功用例还混入先前失败的探索断言。与此同时，截图观测被误交给外部结果读取工具，范围错误丢失类型信息，使尚有修复预算的任务结束。

`play.pointer-gesture` 默认 `mode:probe`。`caseLabel` 只命名，不把探索升级成验收条件。`targetEntityId` 用几何命中事实确认操作对象；未命中先诊断测试坐标。确立正式回归时显式指定 `mode:regression`、名称和原断言，或用 `play.regression promote` 将当前修订下已通过的探测提升为正式用例。用户报告的真实失败应显式登记为正式回归。

序列保留此前输入以重建运行状态；此前探索的断言与目标命中要求作为诊断保留在原记录，不进入新用例的前置断言。此前正式步骤的断言继续有效。正式用例保存时和重放时都要求全部正式断言通过，不能仅用最后一步的结果覆盖前置失败。

v2 测试工件仍由 Operation Log 拥有，不改变 Document 或 Undo。v1 用例按正式回归兼容读取，不默默删除或降级。探索使用独立的 `interaction/probe` 事实，并限制当前索引数量；正式回归在新 Document 修订下仍需重放。

错误测试使用 `play.regression correct`，提交原用例、替代用例和原因。主机要求当前修订、相同初始相机/视口/种子/变换、原用例失败命中证据、替代用例成功命中声明对象，以及相同的行为断言。没有证据的行为失败、断言减弱、不同初始条件或过期证据均被拒绝。旧版无目标字段的用例仅允许单一变换对象且实际命中可验证的保守兼容；旧版没有诊断时须先重放。更正先登记替代正式用例，再追加原用例被替代的事实，关联两份工件与原因；原序列、失败结论和工件保持可查询。中断或工程变更不能把尚未完成的更正算作通过。

`play.evidence.read` 使用已返回的观测引用读取当前任务的状态、轨迹、错误等证据，支持停止 Play、续轮及重启后的读取。文本按 1–8192 字符分页，旧修订明确标记 stale，验收继续遵守原有 provenance 检查。截图返回原图引用、时间点、媒体和尺寸元数据；原 PNG 在任务证据面板供视觉复核，不把 base64 当作可读文本或伪造视觉结论。非观测工件和其他任务的引用拒绝读取。

`studio.result.read` 继续读取受 Session、权限、修订和 TTL 约束的外部工具结果。范围及引用错误使用具体 code，反馈正确工具和读取上限；兼容已有日志里精确匹配的旧式范围错误。自动续轮使用现有修复预算与取消/审批/未知结果门禁。同一观测通过正确工具读取成功后，仅消除该观测误用读取工具的阻塞；历史失败及其他阻塞保留。

验证覆盖探测与正式回归、正式前置失败、旧用例更正与重启、禁止减弱断言、真实 handler 失败拒绝更正、取消和工程隔离、证据分页/归属/截图元数据，以及桌球式混合工具错误的有界恢复。
