# 预览轨道相机接口 · 2026-09-14

根因：Engine 的 OrbitControl 依赖 DOM 画布，而 Play 没有对应的受控脚本接口。camera.author 是 Document authoring 操作，无法表示运行时拖拽。旧示例要求脚本查找并断言原生球面相机，容易造成模型拒绝实现或生成不匹配的相机代码。

新增 api.scene.orbitControls，每 tick 调用，统一在 ReplayInput 固定步长输入上驱动 Engine SphericalTransform3D。all 用于简单查看器，background 按 down 命中归属排除物体手势。一个脚本负责相机；停止、失焦及中断调用释放手势。默认项目相机和根层级场景 3D 相机均支持；后者的变换转换仅发生在 Play 中。

编译声明、能力披露、script.propose 工具说明、按需文档、独立示例与组合拖拽示例同步更新。
