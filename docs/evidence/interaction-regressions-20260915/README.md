# 组合对象交互修复机制验证

日期：2026-09-15。范围为 AIStudio 通用能力，未修改当前用户工程，未重启正在运行的 AIStudio。

## 实现

- 项目/文档范围保存完整手势前序、原始期望及基线；跨对话、日志重新打开后可读取。`play.regression` 支持 list/inspect/replay。修复后须在当前文档修订重新通过保留用例，才能完成 task.evaluate。
- 旋转验收读取真实 Engine 世界矩阵：检查指定运动根、后代与其他对象、世界轴/枢轴/有符号角度，以及松手前实际中间变换。脚本自报计数或角度不能代替这些数据。
- `api.scene.transforms` 提供世界/局部坐标、相机投影方向与拖拽角度，以及世界矩阵快照/绝对旋转；父空间转换、连续跨轴与取消不依赖欧拉角累加。
- 装饰网格使用已有 Engine Interactive.penetrable；编辑器允许启用 pointer 组件并配置 penetrable:true / events:[]。保持渲染，无需脚本，指针射线穿过装饰命中本体；不是物理碰撞开关。
- 分工指导与示例拆开相机控制、对象操作、独立规则。脚本 AST 检查阻止 orbitControls + 对象输入 + 对象变换/改色混写；不声称可判定所有业务职责或所有别名形式。
- Agent Play 从暂停状态开始录制。重放复用首次基线采样，起止 tick 与原序列一致；整条序列结束后汇总成功/失败，前置失败不会被最后一个成功手势覆盖。重复失败保护按整条回归用例计算。

## 范围与限制

这些验证证明工具、宿主和确定性回归机制有效，尚未证明模型重新生成任意魔方游戏均能正确实现。

回归重放保留原始期望，要求相同初始相机、视口、seed 与实体变换；它不是任意脚本内存快照恢复。必须从初始暂停 Play 录制完整 pointer-gesture 前序。单独 play.input/play.step 等未记录的历史会显式标为不可忠实重放。当前每个项目/文档最多 64 个用例、每条 32 个手势。

现有游戏不会自动改写为新 API 或自动拆分旧脚本；Agent 后续修复可通过新增文档与工具应用这些机制。
