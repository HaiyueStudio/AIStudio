# 手机独立视口与扫码图标

日期：2026-11-22

用户已在 iPhone 15 Plus / Safari 确认触屏退出问题解决，并要求手机使用自己的屏幕运行。手机画布现改为铺满当前浏览器可见区域，不再以电脑预览的尺寸或宽高比缩成中间的小画面。横竖屏、VisualViewport 高度变化及全屏状态变化都会更新布局，iframe 内的 Canvas 和相机投影同步调整。

手机相机按短边保留配置视野，避免改成纵屏后裁掉棋盘两侧；二维正交和三维透视投影均保持比例。该展示策略只在手机启动选项中启用，不修改工程数据、原始相机参数或已批准执行计划；桌面预览的投影语义保持不变。手机游戏画面不再显示运行环境的开发提示标牌。Safari 的浏览器工具栏是否隐藏仍取决于其全屏 API，普通浏览器模式会铺满实际可用区域。

“扫码运行”改为纯 SVG 图标，保留可访问名称，hover 或键盘聚焦 1000ms 后通过公共 Tooltip 显示说明。Web 端隐藏按钮及其 Tooltip，不保留空占位。分享仍绑定已消费的执行计划及文档修订；电脑预览尺寸改变不会重新启动分享或中断手机。
