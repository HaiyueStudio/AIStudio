# 项目日志隔离

项目日志面板、日志导出及 Agent `diagnostics.query` 现在由主进程/工具运行时的当前项目身份限定范围。未打开项目时不读取全局日志；携带其他项目身份或旧项目分页游标的请求会被拒绝。项目快照和日志面板的事件数量也按项目计算。

Operation Log 保留应用级追加式 journal，用于启动、存储健康与恢复诊断。新增可重建的项目索引，在扫描预算与关联扩展之前选择项目分区。新事件持久化项目归属；历史事件仅依据明确项目标记或无歧义的 Session/Document 归属建立派生索引。仅有实体名等可复用身份、无法确定归属的旧记录继续属于应用日志，不自动迁移给当前项目，也不改写原始 journal。已有 `.aistudio/agent` 项目记录保存/首次保存迁移机制继续使用。

IPC 请求在开始时捕获所属项目，完成/失败事实仍写入该项目。日志读取前后验证当前项目；切换时前端清空事件、筛选、展开状态与游标，并通过请求代次丢弃旧响应。工具调用在 prepare 时绑定项目/文档，诊断查询使用工作区提供的身份；事务回执查询同样限定当前项目/文档。预览运行错误和停止事件补齐文档归属，预览/视口 IPC 报告补齐项目归属。
