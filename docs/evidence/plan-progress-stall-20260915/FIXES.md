# 计划进度滞后与恢复卡点修复

本轮在此前只读诊断基础上实施修复。未重启用户的 AIStudio，也未修改运行中的魔方工程。

## 修复边界

1. 持久审批按同一任务、文档及精确操作身份恢复，不依赖模型 session 不变。身份包括工具版本、目标、修订、参数/预览摘要和风险。恢复前持久记录消费事实；并行重试也不能重复消费一次授权。工具服务仍重新校验授权。已批准计划同样跨 session 按任务恢复，保留原步骤。
2. 保留最近 8 次真实操作结果。恢复或连续 6 次完成操作未报告步骤时，向模型返回进度核对请求。旧步骤显示“进度待同步”，由明确步骤报告解除；不根据工具数量自动判定建模完成。进度报告可在业务预算检查点更新，但仍校验参数和批准范围。此机制减少过期状态误导，不能保证模型从此不遗漏报告。
3. `scene.query` 返回可回填的 `nextQuery`。同一查询 reader 能补齐 cursor-only 请求的原 scope/projection/revision；明确更改查询条件仍拒绝。缓存有容量限制；跨 reader 应回填完整查询参数。
4. 独立脚本提案可在当前修订重新验证保留的源码，生成新提案后走正常预览和审批。若目标 owner 或脚本改变则报冲突，避免覆盖。此能力依赖仍保留的提案，不宣称支持重启后恢复未持久化源码。
